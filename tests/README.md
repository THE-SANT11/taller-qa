# Pruebas de software

## Objetivo

Esta carpeta está destinada a organizar las pruebas ejecutables del proyecto.

## Pruebas previstas

- **Pruebas de regresión:** comprobar que los cambios no afecten funciones existentes.
- **Pruebas funcionales:** verificar que las funciones del sistema respondan correctamente.
- **Pruebas de seguridad:** revisar posibles vulnerabilidades mediante herramientas como CodeQL y Dependabot.

## Estado actual

La automatización configurada en GitHub Actions realiza comprobaciones básicas del flujo de trabajo. Las pruebas funcionales y de regresión de la aplicación deberán incorporarse cuando se disponga del código fuente y de los requisitos del sistema.
