# Proyecto de pruebas de software

## Objetivo
Identificar y prevenir errores mediante pruebas ágiles, pruebas en la nube y pruebas de seguridad.

## Pruebas seleccionadas

1. **Prueba ágil:** pruebas de regresión automatizadas para verificar que los cambios no afecten funciones existentes.
2. **Prueba en la nube:** ejecución automatizada de pruebas mediante GitHub Actions.
3. **Prueba de seguridad:** análisis de vulnerabilidades con Dependabot y, cuando sea compatible, CodeQL.

## Beneficios esperados
- Detectar errores antes de integrar cambios.
- Comprobar el funcionamiento del software en un entorno automatizado.
- Identificar vulnerabilidades y reducir riesgos de seguridad.
